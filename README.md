# Drive Music — 구글 드라이브 음악 플레이어

구글 드라이브에 올려둔 음악 파일을 맥·휴대폰 브라우저에서 바로 듣는 플레이어입니다.
서버가 따로 없어요. 파일 3개(`index.html`, `app.js`, `config.js`)가 전부입니다. (인터넷 없이 앱을 열게 해 주는 `sw.js` 하나가 더 있어요 — 손댈 일은 없어요)

- 드라이브 폴더 고르기 → 그 안(하위 폴더 포함)의 mp3·m4a·flac·wav·ogg·aac 파일을 목록으로
- 재생 / 일시정지 / 이전 / 다음 / 섞기 / 반복(전체·한곡)
- **플레이리스트**: 곡 옆 ＋ 로 담기, ♥ 로 즐겨찾기, 순서 바꾸기·빼기·이름·삭제. 드라이브에 `drive-music-playlists.md` 한 파일로 저장돼서 맥·폰 어디서든 같은 목록
- 휴대폰 잠금화면·이어폰 버튼으로 조작 가능
- 마지막으로 열었던 폴더와 듣던 곡을 기억
- 곡을 통째로 받지 않고 바로 들음(드라이브 주소를 오디오에 그대로). 다음 곡은 미리 준비해 둬서 곡이 바뀔 때 기다리지 않음
- 뒤에서 듣다 멈춘 채 돌아오면 하단에 **이어 듣기** 단추 하나
- **받아 두기**: 곡·앨범·플레이리스트를 폰에 받아 두면 지하철·비행기처럼 인터넷이 없어도 들을 수 있음

## 1. 구글에서 "앱 열쇠(클라이언트 ID)" 받기 — 한 번만

구글 입장에서 "이 플레이어가 네 드라이브를 읽어도 되니?" 하고 물어볼 때 쓰는 열쇠예요. 10분 정도 걸립니다.

1. https://console.cloud.google.com 에 들어가서 구글 계정으로 로그인
2. 위쪽 프로젝트 선택 → **새 프로젝트** → 이름 `drive-music` → 만들기 → 만든 프로젝트 선택
3. 왼쪽 메뉴 **API 및 서비스 → 라이브러리** → `Google Drive API` 검색 → **사용(Enable)**
4. **API 및 서비스 → OAuth 동의 화면** (화면에 따라 "Google Auth Platform → 브랜딩"으로 보일 수 있음)
   - 앱 이름 `Drive Music`, 지원 이메일은 본인 메일
   - 사용자 유형(대상)은 **외부**
   - **테스트 사용자**에 본인 구글 계정 추가 ← 이걸 안 하면 로그인이 막힙니다
5. **API 및 서비스 → 사용자 인증 정보 → + 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**
   - 애플리케이션 유형: **웹 애플리케이션**
   - **승인된 JavaScript 원본**에 아래 둘을 추가 (리디렉션 URI는 비워둬도 됨)
     - `http://localhost:8000`  ← 맥에서 쓸 때
     - `https://lsc2016.github.io`  ← 휴대폰에서 쓸 때 (3번에서 올릴 주소)
   - 만들기 → `123456…-abc.apps.googleusercontent.com` 모양의 긴 문자열이 **클라이언트 ID**
6. `config.js` 를 열어 `CLIENT_ID` 따옴표 안에 그 문자열을 붙여넣고 저장

> 이 ID는 "어느 주소에서 온 앱인지"를 확인하는 용도라 공개돼도 괜찮아요. 비밀번호 같은 게 아닙니다.
> 처음 로그인하면 "Google에서 확인하지 않은 앱" 경고가 떠요. 본인이 만든 앱이니 **고급 → (안전하지 않음)으로 이동 → 계속**을 누르면 됩니다. (테스트 상태라 뜨는 거고, 테스트 사용자로 등록한 본인 계정만 쓸 수 있습니다.)

## 2. 맥에서 실행하기

`index.html` 을 더블클릭으로 열면 구글 로그인이 **안 됩니다**. 작은 서버로 띄워야 해요.

```bash
cd ~/my_app/drive-music-player
./serve.sh
```

그다음 브라우저에서 http://localhost:8000 을 엽니다. 끌 때는 터미널에서 `Ctrl+C`.

## 3. 휴대폰에서도 쓰기 — GitHub Pages에 올리기

폰에서 열려면 인터넷 주소가 있어야 해요. GitHub Pages가 무료고 간단합니다.

```bash
cd ~/my_app/drive-music-player
git init
git add .
git commit -m "Drive Music 첫 버전"
gh repo create drive-music-player --public --source=. --push
```

(`gh`가 없으면 github.com 에서 `drive-music-player` 저장소를 만들고 push 하면 됩니다.)

GitHub 저장소 페이지 → **Settings → Pages → Branch: main / (root) → Save**.
1~2분 뒤 **https://lsc2016.github.io/drive-music-player/** 로 열립니다.

휴대폰에서 그 주소를 연 다음 **홈 화면에 추가**해 두면 앱처럼 쓸 수 있어요.

> 1번의 "승인된 JavaScript 원본"에 `https://lsc2016.github.io` 가 들어있어야 폰에서 로그인이 됩니다.

홈 화면에 추가하면 초록 바탕 흰 음표 앱 아이콘으로 설치됩니다 (아이폰: 사파리 공유 버튼 → 홈 화면에 추가).

## 쓰는 법

1. **구글로 로그인** → 드라이브 읽기 허용
2. 드라이브에 **Music** 폴더가 있으면 로그인하자마자 바로 열림. 없으면 폴더 고르기 화면에서 이름을 입력하고 찾기(비우고 찾으면 최근 수정된 폴더 20개). 한 번 고른 폴더는 기억해서 다음부터 바로 열림
3. 곡 누르면 재생. 하단 플레이어로 조작
   - **목록 머리의 [▶ 재생] [⇄ 섞기] = 지금 보이는 목록 전체**를 차례로(또는 섞어서) 재생. 곡 목록이면 전체 곡, 아티스트 목록이면 모든 아티스트의 곡(이름 → 앨범 → 트랙 순), 10cm를 열었으면 10cm 곡만, 검색으로 걸렀으면 그 결과만. 하단 작은 글씨에 "♪ 전체 곡", "♪ 아티스트: 10cm", "♪ 검색: 사랑"처럼 어디서 틀었는지 나옴
   - 아래 플레이어의 곡 이름(또는 표지)을 누르면 **다음 곡 목록**이 나와요. 맨 위 초록 줄이 지금 곡, 그 아래가 실제로 나올 순서(섞기를 켰으면 섞인 순서, 전체 반복이면 "처음부터 다시" 뒤로 앞 곡들). 눌러서 바로 건너뛸 수 있어요. 곡이 많으면 100곡까지만 보이고 나머지는 "외 N곡"
   - 앱을 다시 열면 하단에 지난번 곡이 올라와 있고, 하단 ▶를 누르면 지난번 그 목록(섞기 여부까지) 그대로 이어서 재생. 듣던 곡이면 듣던 자리(초)부터
   - **이어 듣기**: 폰에서 다른 앱을 쓰다(또는 잠금화면에서) 돌아왔는데 소리가 멈춰 있으면, 하단 플레이어 맨 위에 초록 **▶ 이어 듣기** 단추가 떠요. 누르면 멈춘 그 자리부터 다시 나와요. 구글 연결이 끊겼을 때도 이 단추 하나만 누르면 돼요. ⏸로 직접 멈춘 때는 안 떠요
   - 홈 화면 아이콘으로 열었으면 곡 목록 위에 "뒤에서 듣다 끊기면 사파리 탭으로 열어 보세요" 한 줄이 떠요. ✕ 로 닫으면 다시 안 보여요
4. 맨 위 오른쪽 **⚙(톱니바퀴) = 설정 메뉴**. 누르면 아래에서 메뉴가 올라와요
   - **폴더 바꾸기** (작은 글씨에 지금 폴더 이름) → 다른 폴더 고르기
   - **새로고침** → 드라이브에 새로 올린 곡 반영
   - **태그 전부 다시 읽기** → 모든 곡 정보를 파일에서 처음부터 다시 (파일의 태그를 고쳤을 때)
   - **로그아웃**(빨간 글씨, 맨 아래) → 바로 나가지 않고 "로그아웃할까요?"를 한 번 더 물어봐요. [로그아웃]을 눌러야만 나감
   - 새로고침·태그 다시 읽기는 곡 목록 화면에서만 눌려요(폴더 고르기 화면에선 흐림)
   - 맨 위 로고(초록 동그라미 + **Drive Music**)를 누르면 첫 화면(곡 목록)으로 돌아와요. 듣던 곡은 그대로 계속 나옴
5. 맨 위 칩 줄 **[곡] [아티스트] [앨범] [작곡가] [장르] [언어] | [플레이리스트]** 가 메뉴. 앞쪽 칩은 보관함 보기, 구분선 뒤 **플레이리스트** 칩은 플레이리스트 목록. 폰에서 다 안 보이면 칩 줄을 옆으로 밀기. 마지막에 보던 칩을 기억해서 다음에 열면 그 칩
6. 보관함 칩일 때 검색 칸에 글자를 치면 바로 걸러짐 (비우면 전체). "곡"에선 제목·가수·앨범·폴더 이름, 이름 목록에선 이름, 묶음 안에선 그 안의 곡. 걸러진 곡을 눌러도 다음 곡·섞기는 거르기 전 목록 기준

**보관함 분류** (맥 "음악" 앱처럼)
- 맨 위 칩 줄에서 **곡 | 아티스트 | 앨범 | 작곡가 | 장르 | 언어** 고르기. 기본은 "곡" = 폴더의 전체 곡
- 아티스트·앨범·작곡가·장르를 고르면 이름 목록(가나다·ABC 순, 곡 수 표시). 앨범은 "앨범 이름 / 아티스트" 두 줄
- 이름을 누르면 그 안의 곡이 펼쳐짐 (왼쪽 위 ‹ 로 이름 목록에 돌아감). 앨범 안은 트랙 번호 순, 나머지는 앨범 → 트랙 순
- 거기서 곡을 누르거나 줄 오른쪽 **▶**·위쪽 **재생**을 누르면 그 묶음만 이어서 재생. 하단 플레이어 작은 글씨에 "♪ 앨범이름"처럼 어디서 틀었는지 나옴
- 태그가 비어 있는 곡은 "알 수 없는 아티스트(앨범·작곡가·장르)"로 묶여 맨 아래
- 마지막에 보던 분류·묶음을 기억해서 다음에 열면 그 자리

**태그 고치기·묶음 합치기** — 음악 파일 자체는 안 바뀌고, 드라이브의 `drive-music-library.md`에 적힌 정보만 바뀜
- 합치기: 아티스트·앨범·작곡가·장르 이름 목록 오른쪽 위 **편집** → 합칠 줄 체크(2개 이상) → 아래 **합치기** → 남길 이름을 고르거나 새로 적기. 예: "10CM", "십센치"를 "10cm" 하나로
- 맥(마우스)에서는 편집을 안 눌러도 한 줄을 다른 줄 위로 끌어다 놓으면 합치기 창이 뜸
- 이름 바꾸기: 편집 중에 줄 오른쪽 ✎ 또는 줄을 길게 누르기 → 그 묶음 전체 곡에 적용
- 곡 하나 고치기: 곡 줄 오른쪽 **⋯ → 태그 편집**. 제목·아티스트·앨범·앨범 아티스트·작곡가·장르·트랙·연도 (아티스트·앨범·장르 칸은 있는 이름에서 고를 수 있음)
- 되돌리기: 고친 직후 아래 알림의 **되돌리기**(5초), 또는 보관함 머리 **⋯ → 마지막 변경 되돌리기**
- **언어**(한국어·중국어·영어·일본어·기타)는 제목·아티스트 글자를 보고 자동으로 채움: 한글이 있으면 한국어, 가나(あ·ア)가 있으면 일본어, 한자만 있으면 중국어, 로마자면 영어. 그래서 한자만 쓴 일본 곡(예: 米津玄師)은 중국어로, 영어 이름 K-pop은 영어로 잡힐 수 있음 → 곡 **⋯ → 태그 편집**의 "언어"에서 고르거나, 아래 태그 목록 편집에서 묶어 옮기기
- **태그 목록 편집** 화면: 보관함 머리 **⋯ → 태그 목록 편집**. 위에서 아티스트·앨범·작곡가·장르·언어를 고르면 값들이 곡 수와 함께 나옴. 줄 오른쪽 **≡** 를 잡고 다른 값 위에 놓으면 "몇 곡이 바뀌는지" 보여주고 확인하면 합침(폰 손가락으로도 됨). **✎** 는 이름 바꾸기. 왼쪽 위 ← 로 보관함에 돌아감
- 앱에서 고친 곡은 태그를 다시 읽어도 고친 값이 그대로. "태그 전부 다시 읽기"(맨 위 **⚙** 또는 보관함 **⋯**)를 할 때만 "고친 태그도 버릴까요?"를 물어봄

**곡 정보(태그)**
- 음악 파일 안에 적힌 제목·가수·앨범·앨범표지를 읽어서 목록에 보여줌. 곡 이름 아래 작은 글씨가 "가수 · 앨범"
- 폴더를 처음 열면 목록 위에 "태그 읽는 중 37/120"이 뜸. 파일 전체가 아니라 앞부분(정보가 적힌 곳)만 받아서 빠름. 읽는 중에도 곡을 누르면 바로 재생됨
- 읽은 정보는 드라이브 맨 위 `drive-music-library.md`에 적어둠. 다음부터는 이 파일을 먼저 읽고 새로 생긴 곡만 읽음 (표지 그림은 안 적고, 재생할 때 그 곡에서 다시 꺼냄)
- 맨 위 **⚙ → 새로고침** = 새 곡만 읽기, **⚙ → 태그 전부 다시 읽기** = 모든 곡 태그를 처음부터 다시 — 파일의 태그를 고쳤을 때
- 하단 플레이어 초록 네모와 잠금화면에 앨범 표지가 나옴 (표지 없는 곡은 음표 그대로)

**플레이리스트**
- 보관함 칩(곡·아티스트 등)에서 곡 오른쪽 **＋** → 담을 플레이리스트에 체크 (없으면 아래 칸에 이름 쓰고 ＋ 로 새로 만들며 담기)
- 하단 플레이어의 **♥** → 지금 곡을 "즐겨찾기"에 바로 담기/빼기
- 칩 줄 끝 **플레이리스트** 칩 → 목록 아래 칸에 이름 쓰고 ＋ 로 새로 만들기. 하나 열면 **재생 / 섞어서 / 편집**. 편집에서 ↑↓ 로 순서, ✕ 로 빼기, 이름 바꾸기·삭제
- 저장은 드라이브 맨 위에 생기는 `drive-music-playlists.md`. 마크다운이라 직접 열어 고쳐도 됨 (줄 모양 `- 제목 | 파일ID | 폴더` 유지)
- 처음 로그인할 때 "Google Drive에서 이 앱으로 열거나 만든 파일 보기·수정" 허용이 하나 더 뜨는데, 그게 이 파일 하나 쓰기 위한 것

**받아 두기 (인터넷 없이 듣기)**
- 받기: 곡 줄 오른쪽 **⋯ → ↓ 받기**, 또는 앨범·아티스트 안이나 플레이리스트 상세 머리의 **[↓ 받기]** (그 목록에서 아직 안 받은 곡만). 다 받았으면 칩이 **✓ 받음**으로 바뀜
- 한 번에 한 곡씩 조각(3MB)으로 받아요. 화면 맨 위에 "받는 중 3/12곡 · 45%" 한 줄. 받은 곡은 줄 오른쪽에 작은 초록 **↓**, 받는 중이면 **%**
- 끊겨도 받은 데까지는 남아서, 인터넷이 돌아오거나 앱을 다시 열면 그 자리부터 이어 받아요. 화면을 끈 채(뒤에서)는 구글 연결이 끝나면 쉬었다가 앞으로 오면 이어 받음
- 받기 전에 남은 자리를 봐요. 모자라면 받지 않고 "자리가 모자라요 — 필요 ○GB, 남은 ○GB"
- 받은 곡은 늘 폰에 받아 둔 것부터 틀어요(인터넷·구글 연결 없이). 다음 곡이 받은 곡이면 곡이 바뀔 때도 기다림 없음
- **⚙ → 받은 곡**: 받은 곡 수·용량, 남은 자리, "안 지워짐 / 사파리가 지울 수 있음"이 보이고, [▶ 재생] [⇄ 섞기], 곡마다 ✕ 로 지우기, 맨 아래 **전부 지우기**(한 번 더 물어봄). 지워도 드라이브의 원래 파일은 그대로. 듣는 중인 곡을 지우면 그 곡은 끝까지 나오고 저장소에서만 지워져요
- **인터넷이 없을 때 앱을 열면** 로그인 대신 받은 곡만 보이는 목록이 열려요(맨 위 "인터넷이 없어요 — 받은 곡만 보여요"). 플레이리스트도 받은 곡만. 쓰다가 인터넷이 끊겨도 목록이 받은 곡만으로 바뀌고, 돌아오면 원래대로
- 인터넷이 없을 땐 태그 고치기·플레이리스트 고치기·♥ 를 막아요(드라이브에 올릴 수가 없어서). 인터넷이 돌아오면 다시 돼요
- 로그인 화면에 "받아 둔 곡 N곡 듣기 (로그인 없이)" 단추 — 로그인하지 않고 받은 곡만 듣기
- 로그아웃해도 받은 곡은 남아요

키보드: `스페이스` 재생/정지, `←/→` 10초 이동, `Shift+←/→` 이전/다음 곡

## 자주 나오는 문제

| 증상 | 원인·해결 |
|---|---|
| 로그인 창이 뜨다 바로 닫히며 `origin` 어쩌고 오류 | 1-5번 "승인된 JavaScript 원본"에 **지금 열고 있는 주소**가 없음. 추가 후 몇 분 기다렸다 다시 |
| "액세스 차단됨: 앱이 확인되지 않음" | 1-4번 **테스트 사용자**에 본인 계정이 안 들어감 |
| 폴더는 보이는데 곡이 0개 | 파일 확장자가 목록(mp3·m4a·flac·wav·ogg·aac·opus)에 없거나, 공유 드라이브 권한 문제 |
| 플레이리스트 탭에 "저장 실패" | 드라이브 쓰기 허용을 안 했거나(로그아웃 후 다시 로그인하며 허용) 잠깐 인터넷 끊김. 5초마다 다시 시도함 |
| 플레이리스트 곡에 "다른 폴더의 곡" | 지금 연 폴더엔 없는 곡. 재생은 됨 |
| 폴더 바꾸기·새로고침·로그아웃 아이콘이 없어짐 | 맨 위 오른쪽 **⚙** 하나로 모았어요. 누르면 메뉴에 글자로 나와요. 로그아웃은 ⚙ 안에 있고 한 번 더 물어봐서, 잘못 눌러도 나가지 않아요 |
| 홈 화면에 추가한 앱에서 맨 위 ⚙ 아이콘이 안 보임 | 홈 화면 앱은 화면을 시계 줄까지 꽉 채워서, 예전엔 아이콘이 시계 줄 뒤에 숨었음. 지금은 그만큼 내려서 보임. 그래도 안 보이면 앱을 완전히 닫았다가(위로 쓸어 올려 끄기) 다시 열기 |
| 첫 화면이 느림 | 예전엔 폴더 고르기 화면이 드라이브의 모든 폴더를 가져와서 느렸음. 지금은 로그인하면 **Music** 폴더(config.js의 `DEFAULT_FOLDER_NAME`)를 한 번만 찾아 바로 열고, 폴더 화면은 입력하고 찾을 때만 검색함. 음악 폴더 이름이 다르면 `DEFAULT_FOLDER_NAME`을 그 이름으로 바꾸거나, 폴더 화면에서 한 번 골라두면 다음부터 바로 열림. 곡 목록은 지난번 것을 먼저 보여주고 뒤에서 새로 읽음 |
| 기억된 폴더를 지웠더니 엉뚱한 폴더가 열림 | 기억된 폴더가 없어지면 Music 폴더를 다시 찾아 열어요. 다른 폴더를 쓰려면 맨 위 **⚙ → 폴더 바꾸기**로 고르기 |
| 폴더 고르기 화면에서 돌아가려면? | 왼쪽 위 **←**, 또는 맨 위 로고(**Drive Music**)를 누르면 보던 폴더의 곡 목록으로 바로 돌아가요(다시 찾을 필요 없음, 듣던 곡도 안 끊김). 처음 로그인해서 아직 연 폴더가 없을 땐 돌아갈 곳이 없어서 아무 일도 안 일어나요 — 폴더를 하나 골라 주세요 |
| 다음 곡 목록에서 순서를 바꾸거나 빼고 싶음 | 아직은 보기와 눌러서 건너뛰기만 돼요. 순서를 바꾸려면 플레이리스트를 만들어 편집에서 ↑↓ 로 |
| 1시간쯤 지나면 잠깐 멈춤 | 구글 열쇠가 1시간짜리라 조용히 다시 받는 중. 자동으로 이어짐 |
| 한참 듣다 재생이 멈추고 아래에 "구글 연결이 끊겼어요" | 구글 열쇠(1시간짜리)를 조용히 다시 받지 못한 것. **▶를 한 번 눌러 주세요** — 누르는 순간 구글 연결을 다시 받아서 이어 틀어요. 20초 넘게 구글이 답하지 않으면 빙글이가 멈추고 이 안내가 떠요(예전엔 빙글이만 계속 돌았음). 태그 읽기도 그동안 쉬고, 다음에 폴더를 열면 이어 읽어요 |
| 폰에서 처음 곡은 ▶를 눌러야 소리가 나요 | 폰 브라우저는 "손으로 누른 직후"에만 소리를 내게 해요. 큰 파일(flac 등)은 받는 동안 그 시간이 지나서, 아래에 "▶를 눌러 재생하세요"가 떠요. 곡은 이미 받아 둔 상태라 **▶ 한 번이면 바로** 나와요 |
| 새로고침했더니 듣던 곡이 끊김 | 고쳤어요. ⚙ → 새로고침이나 로고로 돌아가도 지금 듣는 곡의 파일은 안 지워요. 그래도 끊기면 그 곡을 한 번 다시 받아서 이어 틀어요 |
| 곡이 계속 다음, 다음으로 넘어가기만 함 | 재생하지 못하는 파일이 이어진 것. 3곡 연달아 실패하면 멈추고 "3곡 연달아 재생하지 못해 멈췄어요"가 떠요. 인터넷을 확인하고 ▶ |
| 뒤로가기를 누르면 앱이 닫힘 | 고쳤어요. 폴더 고르기·플레이리스트·태그 목록 편집 화면에선 왼쪽 위 **←** 와 브라우저(홈 화면 앱) 뒤로가기가 같은 곳(곡 목록)으로 가요. 아래에서 올라오는 창은 오른쪽 위 **✕**, `Esc`, 바깥 누르기로 닫혀요 |
| 곡 이름이 파일 이름 그대로, 아래 작은 글씨가 파일 크기 | 그 파일 안에 태그가 없음(또는 ogg·wav처럼 태그를 못 읽는 형식). 이때 제목은 파일 이름, 앨범은 폴더 이름으로 둠. 맥의 "음악" 앱이나 Mp3tag 같은 프로그램으로 태그를 넣은 뒤 맨 위 **⚙ → 태그 전부 다시 읽기** |
| 파일의 태그를 고쳤는데 목록이 그대로 | 이미 읽은 곡은 `drive-music-library.md`에 적힌 걸 씀. 맨 위 **⚙ → 태그 전부 다시 읽기**를 누르면 전부 다시 읽음 (앱에서 고친 곡은 "고친 태그도 버릴까요?"에서 확인을 눌러야 파일 태그로 돌아감) |
| 앱에서 고친 태그가 맥 "음악" 앱엔 안 보임 | 정상. 앱에서 고친 건 음악 파일이 아니라 `drive-music-library.md`에만 저장됨 |
| 큰 파일(수십 MB)이 재생 전 조금 기다림 | 이제는 통째로 받지 않고 바로 들어서 거의 안 기다려요. 아래에 "(대체됨)"이 뜬 접속에서만 예전처럼 통째로 받은 뒤 재생(다음 곡은 미리 받아둠) |
| 아래에 "바로 듣기가 안 돼 통째로 받아 틀어요(대체됨)" | 구글이 바로 듣기 주소를 받아 주지 않아, 이번 접속 동안은 예전 방식(곡을 통째로 받은 뒤 재생)으로 바꾼 것. 들을 수는 있지만 큰 곡은 기다리고, 뒤에서 들을 때 곡이 바뀌며 끊길 수 있어요. 자주 뜨면 알려 주세요 |
| 아이폰에서 다른 앱(지도 등)을 앞에 두면 끊겨요 | 아이폰은 뒤에 있는 웹앱을 자주 재워요. ① 홈 화면 아이콘 대신 **사파리 탭으로 열어** 들어 보세요(홈 화면 앱이 더 잘 끊겨요) ② 돌아와서 멈춰 있으면 하단 **▶ 이어 듣기** 한 번이면 그 자리부터 ③ 잠금화면·이어폰 ▶ 도 같은 길이라 끊긴 뒤에도 눌러 보세요 |

| 아래에 "받은 곡이 지워졌어요 — 다시 받기" | 폰(사파리)이 자리가 모자라 받아 둔 곡을 지운 것. 알림의 **다시 받기**나 **⚙ → 받은 곡** 맨 위 **다시 받기**를 누르면(인터넷이 있을 때) 다시 받아요. 받은 곡이 지워진 채 틀면 "받은 곡이 지워져 드라이브에서 틀어요"가 뜨고 드라이브에서 바로 들어요 |
| 받아 둔 곡이 며칠 뒤 다 없어짐(알림도 없이) | 사파리가 사이트 저장소를 통째로 지우면 "받았었다"는 기록까지 같이 지워져 알릴 수가 없어요. **홈 화면 아이콘**으로 쓰면 덜 지워져요. ⚙ → 받은 곡 줄에 "안 지워짐"이면 브라우저가 지우지 않기로 한 것, "사파리가 지울 수 있음"이면 지울 수 있다는 뜻 |
| "이 브라우저에선 받아 두기를 못 해요" | 그 브라우저(예: 사파리 개인 정보 보호 모드)가 저장소(IndexedDB)를 못 쓰게 함. 받기 단추가 꺼져요. 보통 창(홈 화면 아이콘·사파리 탭)에서 열어 주세요 |
| "자리가 모자라요" | 폰에 남은 자리보다 받을 곡이 큼. ⚙ → 받은 곡에서 안 듣는 곡을 지우거나 더 적게 골라 받기 |
| "받기 실패: … 다음에 이어 받아요" | 인터넷이 끊겼거나 구글 연결이 끝난 것. 받은 데까지는 남아 있고, 인터넷이 돌아오거나 앱을 다시 열면 이어 받아요 |
| 인터넷이 없는데 "인터넷이 없어요. 받아 둔 곡이 없어서 틀 게 없어요" | 받아 둔 곡이 하나도 없음. 인터넷이 있을 때 곡을 받아 두세요 |
| 고친 코드가 폰에 안 보임 | 앱 파일은 "인터넷 먼저"라 보통 바로 바뀌어요. 그래도 옛것이면 앱을 완전히 닫았다 다시 열기 |

## 확인할 것 (사람이 폰에서)

- 플레이리스트 하나를 받고 → 비행기 모드 → 잠근 채 세 곡이 넘어가는지 (홈 화면 아이콘·사파리 탭 둘 다)
- 비행기 모드에서 앱을 새로 열면 받은 곡 목록이 바로 뜨는지
- **일주일 뒤에도 받은 곡이 남아 있는지** (홈 화면 아이콘·사파리 탭 각각). ⚙ → 받은 곡 줄의 "안 지워짐 / 사파리가 지울 수 있음"도 같이 보기

## 설정 바꾸기 (`config.js`)

- `DEFAULT_FOLDER_NAME`: 로그인하자마자 열 폴더 이름. 기본값 `"Music"` (대소문자 상관없이 이름이 딱 그것인 폴더, 여러 개면 가장 최근 것). `""`로 비우면 항상 폴더 고르기 화면부터
- `INCLUDE_SUBFOLDERS`: 하위 폴더까지 뒤질지 (`true` / `false`)
